# System variable and string label index: 3.691

English labels from the inspected 3.691 translation package: translation by Yumu, edited by Anya and Lolo; sample-data translation by Yumu. Original engine/Basic System by SmokingWOLF. See [sources and credits](sources.md). Reviewed 2026-10-20. This is an installation snapshot, not an engine-version-independent ID registry.

This table contains identifier labels, not full semantics. `[RO]` means read-only and `[P]` means Pro in the source labels. An unmarked label is not proof that assigning to it is safe. Verify writeability, units, and release support before use. Blank/reserved labels are omitted. Numeric reference bases are 9000000 for Sys and 9900000 for SysS.
